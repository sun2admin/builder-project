When proposing design questions, always pose one question at a time and wait for the answer before moving to the next.

**Why:** User wants to deliberate each decision independently without context bleeding between questions. Batched questions also risk a single "a,b,c,d" answer string that loses fidelity if any letter is ambiguous or the user wants to comment on a specific item.

**How to apply:** When multiple SPQ/MKMQ/RPQ/etc. questions are queued, present #1 only with its option table + lean recommendation. Wait for pick. Then ask #2. Repeat. Applies to all sub-plan / design / clarification flows in this project, regardless of caveman mode.
